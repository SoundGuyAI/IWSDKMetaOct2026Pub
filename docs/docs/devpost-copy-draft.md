# Wall Tones 2: Too fast to wall

Proposed public-facing copy for review. Not yet applied to Devpost.

## Tagline

Play a musical memory game at your table in mixed reality. Watch, listen, and repeat the sequence with your hands.

## What it does - placement paragraph

For seated play, place the four pads on a table and repeat the sequence by touching them with your tracked fingertips. You can also place the pads on walls or in the air. A desktop mode lets you play without a headset, and you can choose a recorded male or female host voice.

## How we built it

I built the sequel with Meta's Immersive Web SDK (IWSDK), TypeScript and Vite. The playable web build is hosted on Cloudflare Workers.
