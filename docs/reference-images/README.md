# reference-images

Visual references made for Wall Tones, with an index of Oded's own comments, picks and corrections: see [index.md](index.md).

Files are original bytes at full resolution (not recompressed). Names are prefixed by section: `ui-`, `armband-`, `rift-`, `marketing-`. The upload tool also put a number in front of each image file name (`N-`). `index.md` has the table of stored names.

## Visibility note

This repo is public until Oded makes it private (planned Nov 18, 2026). Everything in this folder is visible until then. Only the references and comments he asked to archive are here. His own photos and screenshots are not.

## Rules for agents working in this repo

- Read `index.md` before changing anything that has a reference. APPROVED, PREFERRED and REJECTED come from Oded's own words. PROPOSED means we made it and he has not judged it.
- Concept art and mockups show direction only. They are not gameplay screenshots and not final art. Placeholder buttons or numbers in a mockup are not approved features.
- Do not copy a rejected image. Keep rejected and superseded versions, and mark them.
- Quote Oded verbatim, typos kept. Do not finish an unfinished sentence for him.
- When you make a new reference image or get new comments, add the file and an index row in the same commit: file name, what it shows, status, his words with date and time.
- Each project keeps its references in its own repo, in a folder like this one. Do not archive another project's assets here.
- No logs, prompts, tool output, agent IDs or credentials in this folder.
- Before a repo goes public, check what this folder shows.
